Key Security Model

    
API keys never touch the browser, blockchain, or logs. Full proxy pattern with signed responses.


    

      

        
🔒 Encryption at Rest

        
API keys are stored as Vercel environment variables, encrypted by Vercel's infrastructure. Locally, stored in .env (gitignored). Never hardcoded.

      

      

        
✍ Response Signing

        
Every proxy response includes an HMAC-SHA256 signature over {data, timestamp}. On-chain keepers verify this before submitting data to contracts.

      

      

        
⚡ Rate Limiting

        
60 requests/minute per IP using express-rate-limit. Forwarded-IP aware for Vercel edge network. Returns 429 on breach.

      

      

        
🌐 CORS Policy

        
Endpoints have CORS headers set. In production, restrict Access-Control-Allow-Origin to your frontend domain only.

      

    


    

      
🔍 Verify a Signed Response

      

        Paste a signed response from any endpoint to verify its signature.
      

      
      

        
      

      

    

  


  
  

    
System Architecture

    
Full data flow from external APIs to on-chain Intelligent Contracts.


    

      
┌─────────────────────────────────────────────────┐
│        Intelligent Contract (On-Chain)           │
│                                                  │
│  IAPIGateway gateway = IAPIGateway(ADDR);        │
│  gateway.requestData("weather","current",...);   │
│  // emits APIRequest event                       │
└──────────────────┬──────────────────────────────┘
                   │  on-chain event
                   ▼
┌─────────────────────────────────────────────────┐
│         Oracle Keeper (Off-Chain Node)           │
│                                                  │
│  • Listens for APIRequest events                 │
│  • Calls IC Proxy Service via HTTPS              │
│  • Verifies HMAC signature on response           │
│  • Submits signed data back on-chain             │
└──────────────────┬──────────────────────────────┘
                   │  HTTPS — API key injected server-side
                   ▼
┌─────────────────────────────────────────────────┐
│     IC Proxy Service (This Repo — Vercel)        │
│                                                  │
│  /api/weather  → OpenWeatherMap API              │
│  /api/price    → CoinGecko API                   │
│  /api/social   → Twitter/X API v2                │
│  /api/verify   → Signature verification          │
│                                                  │
│  • API keys in encrypted env vars                │
│  • Rate limiting (60 req/min/IP)                 │
│  • HMAC-SHA256 response signing                  │
│  • CORS protection                               │
└──────────────────┬──────────────────────────────┘
         ┌─────────┼─────────┐
         ▼         ▼         ▼
   OpenWeather  CoinGecko  Twitter
     API          API      API v2
